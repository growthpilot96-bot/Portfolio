# Portfolio Website

A modern, interactive developer and designer portfolio built with React, TypeScript, Vite, Tailwind CSS, and Framer Motion.

## ✨ Features

- **Dynamic Hero Section**: Interactive particle background, headline typography, and animated status badges.
- **Featured Projects & Case Studies**: Deep-dive case studies with rich metadata, metrics, live links, and interactive modals.
- **Interactive Scope & Budget Estimator**: Interactive calculator allowing clients to configure project requirements and generate real-time estimates.
- **Design Philosophy & Process**: Interactive visual timelines and philosophy breakdowns.
- **Interactive Contact Form & Quick Booking**: Real-time form validation, confetti effects, and direct contact options.
- **Smooth Animations & Micro-Interactions**: Custom magnetic cursor, preloader, and Framer Motion transitions.

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Effects**: [canvas-confetti](https://www.npmjs.com/package/canvas-confetti)

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+ recommended)
- npm or yarn / pnpm

### Installation

1. Clone the repository:
```bash
git clone https://github.com/growthpilot96-bot/Portfolio.git
cd Portfolio
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Build for production:
```bash
npm run build
```

5. Preview the production build:
```bash
npm run preview
```
